# Grux 3.0 work log: every packet, who holds it, what proved it

This file is the ONE source of truth for what is left and what is finished. A
packet that is not in this table does not exist; a packet marked DONE without an
artifact in its Evidence column is not done. Sessions edit only their own rows.

**Status values:** `OPEN` (nobody holds it), `HELD by <session>` (claimed, in
flight), `REVIEW` (branch pushed, waiting on the operator), `DONE` (merged to
main with evidence), `BLOCKED <reason>`, `WAITING ON OPERATOR: <the one decision>`
(everything a session can do is done and evidenced; only the operator's
decision remains), `MOVED to <packet>` (the work continues
under that packet; this row is NOT done, and flips to DONE with the evidence
"closed by <packet>" only when that packet closes).

**Evidence** is a path, an exit code, a quoted line of output, or a screenshot.
"Verified" with nothing attached is not evidence.

## Rules that make this work

1. **One session owns a file at a time.** Before claiming a packet, check the
   Files column of every `HELD` row. If a file overlaps, the packet waits.
2. **Only the build worktree on `main` installs.** Lanes compile and test in
   their own worktree; `./build.sh`, the live app, the sweep and every
   screenshot belong to the operator.
3. **Lanes branch, the operator merges.** Branch `lane/<packet-id>`. Never push
   `main` from a lane.
4. **A packet closes with its test red-proven**, not just green.
5. **Every phase gate is a row too.** The gate closes the phase, not the tasks.
